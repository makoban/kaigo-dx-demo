# 介護のDX　できることデモ

介護施設向けに「こんなことができます」を、実際に触れる形でまとめたものです。
8つとも実際に動きます。スマホ・タブレットでも操作できます。

## デモ一覧

| デモ | 触れること |
|---|---|
| [介護記録・診断書の読み取り](demo/kiroku/) | 手書き記録を撮影→構造化。加算の記録漏れアラート |
| [会議・カンファレンス議事録](demo/gijiroku/) | 録音→要約・決定事項・宿題を自動生成（施設内で処理） |
| [空室・待機リスト・紹介元](demo/kuushitsu/) | 居室グリッド・待機者の自動照合・紹介元別の成約率 |
| [問い合わせ〜入居の管理](demo/kanri/) | 案件ボード。14日以上放置を赤で検知 |
| [給与計算（例外に耐える）](demo/kyuyo/) | 金額をその場で修正→理由が履歴に残る |
| [ご家族への配信・アンケート](demo/kazoku/) | 写真を選んでLINE配信→アンケート集計 |
| [職員のLINE相談窓口](demo/soudan/) | 就業規則AIが参照元つきで即答／匿名相談 |
| [ご入居費用の見積もり](demo/mitsumori/) | 選択→合計→見積書生成→印刷 |

[背景と費用の目安をまとめた資料](dx/)

## ご注意

- **デモに登場する氏名・数値・施設情報・医療機関名は、すべて架空のものです。**
- 実際の画面・項目・計算ルールは、導入先の帳票・料金表・シフトの決まりに合わせて変わります。
- 外部への通信は一切行っていません。すべてブラウザ内だけで動きます。
